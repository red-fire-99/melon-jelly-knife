# Melon Jelly Knife 🍉🔪

> 一个**单文件、零依赖、完全离线**的 Canvas 切水果小游戏。
> 按住鼠标（或手指）拖动挥刀，切开抛起的西瓜、果冻与火龙果，别碰炸弹。

整个游戏就是一个 `index.html`：没有构建步骤、没有 npm 包、没有后端、没有网络请求。克隆下来双击即可玩。

---

## ✨ 功能特性

**玩法**
- 抛物线发射：由目标最高点反推初速度 `v = √(2gh)`，重力随屏高缩放，不同屏幕手感一致
- 刀锋拖尾：按住拖动生成锥形渐隐轨迹，用「点到线段距离」判定切割，快速挥刀也不会漏切
- 7 种目标：西瓜(3分) / 火龙果(3分) / 果冻(2分) / 橙子·柠檬·猕猴桃(1分) / 炸弹(立即结束)
- 果冻弹性：飞行时持续「呼吸」挤压，切开后以阻尼弹簧回弹抖动
- 半块渲染：半平面裁剪 + 切口果肉椭圆 + 切面种子，两半保留惯性并独立旋转
- 连击系统：一刀切中 ≥3 个触发 `COMBO ×N`，额外加分
- 3 条命：水果落地扣命，炸弹漏掉不扣
- 难度曲线：随时间提升出果频率、每波数量与炸弹概率（4% → 20%）

**表现**
- 果汁飞溅粒子、冲击波圆环、浮动 `+N` 分数、屏幕震动
- WebAudio **实时合成**音效（无任何音频文件）
- 玻璃拟态 HUD、粉→橙渐变主色
- `localStorage` 保存历史最佳分与开关设置

**性能**
- 精灵预渲染：每种水果 3 套纹理变体，只在尺寸变化时绘制一次，运行期仅 `drawImage`
- 对象池 + 交换删除（O(1) 移除），消除运行期 GC 抖动
- 碰撞检测先做线段 AABB 粗筛；背景静态层与装饰圆精灵化
- 页面不可见 / 暂停时主循环完全停摆
- 帧率自适应画质三档（L2 / L1 / L0），带滞回避免抖动

## 🚀 安装与运行

### 方式一：直接打开（推荐，零步骤）

```bash
git clone https://github.com/red-fire-99/melon-jelly-knife.git
cd melon-jelly-knife
```

然后**双击 `index.html`** 即可。游戏不使用 `fetch` / `import`，`file://` 协议下也能完整运行。

### 方式二：本地静态服务器

```bash
# Python（无需安装任何依赖）
python -m http.server 8080
# 然后访问 http://localhost:8080

# 或 Node
npx --yes serve . -l 8080

# 或用仓库脚本
npm start
```

> `package.json` 中的 `dependencies` 与 `devDependencies` **均为空**，
> 它只用于声明「本项目零依赖」并提供便捷启动脚本，不需要执行 `npm install`。

## 🎮 使用说明

### 操作

| 操作 | 说明 |
|---|---|
| 按住鼠标 / 手指拖动 | 挥刀切割（必须按住） |
| `空格` | 开始游戏 / 暂停 / 继续 |
| `Esc` | 暂停中继续 |
| 右上角 🔊 | 音效开关 |
| 右上角 ⏸ | 暂停 |

### 配置开关

默认配置即为「经典手感」。另有可选开关，三种方式任选其一：

**1. 开始 / 暂停面板上的拨杆开关**（设置会记住，下次打开自动沿用）

**2. URL 参数**

```
index.html?enhanced=1              # 开启打击感增强包
index.html?fps=1                   # 显示帧率
index.html?sprites=0&autoQuality=0 # 关闭精灵加速、关闭自适应画质
```

**3. 运行时 API**（浏览器控制台）

```js
window.MJK.set({ enhanced: true, fps: true })  // 修改配置
window.MJK.get()                                // 读取当前配置
window.MJK.stats()                              // { fps, level, dpr, fruits, halves, parts }
```

| 开关 | 默认 | 作用 |
|---|---|---|
| `enhanced` | `false` | **打击感增强包**：命中顿帧 60ms + 150ms 慢放、沿刀口法线的方向性震动、全屏缩放冲击、白闪、斩击刀光、三层汁液喷射、两半弹出缩放、三层叠音（低频 thump + 高频脆响 + 汁液噪声） |
| `sprites` | `true` | 精灵预渲染（纯性能）。关闭则走 100% 逐帧绘制路径，用于性能 A/B 对比 |
| `autoQuality` | `true` | 帧率自适应降档 |
| `fps` | `false` | 右上角显示实时 FPS / 画质档 / 实体数 |

### 调参入口

打击感参数集中在源码顶部的 `FEEL` 对象，画质档位在 `PERF` 与 `Q_LEVELS`：

```js
const FEEL = {
  hitStopMs: 60,   // 命中顿帧(ms)
  slowMs: 150,     // 顿帧后慢放时长(ms)
  slowScale: .32,  // 慢放倍率
  shake: 10,       // 震动强度
  punch: .024,     // 全屏缩放冲击
  pop: .40,        // 两半弹出缩放
  flash: .20       // 命中白闪强度
};
```

## 📊 性能

实测（约 7 个水果 + 8 个半块同屏，固定 L2 画质，统计每帧 Canvas 调用）：

| 绘制路径 | 渐变/帧 | drawImage/帧 | arc/帧 | clip/帧 |
|---|---|---|---|---|
| 精灵路径（默认） | **0** | ~30 | **0** | **0** |
| 逐帧绘制（原版路径） | 13.0 | 17.0 | **183** | **11.1** |
| 逐帧绘制 + 增强包 | 12.5 | 17.0 | **243** | 12.5 |

精灵路径把每帧的**路径构建、渐变创建、裁剪全部降为 0**，替换为约 30 次 `drawImage`。
逐帧路径的成本还会随同屏水果数线性增长（每个水果至少 2 次 `arc`，猕猴桃 / 柑橘再各加 40 / 34 次散点绘制）。

想自己对比：打开 `?fps=1`，切换「精灵加速渲染」开关，观察右上角 FPS。

## 📁 目录结构

```
melon-jelly-knife/
├── index.html        # 游戏本体（HTML + CSS + JS 全部内联，唯一必需文件）
├── README.md         # 本文件
├── LICENSE           # MIT
├── package.json      # 依赖声明（零依赖）+ 启动脚本
├── .gitignore        # 忽略密钥、依赖、本地工作区等
├── .env.example      # 环境变量约定示例（当前项目无需任何密钥）
└── .gitattributes    # 统一换行符为 LF
```
源码内模块划分（均在 `index.html` 的 `<script>` 中，按顺序）：

```
1. CONFIG 开关 / PERF 画质档 / FEEL 打击感参数
2. Sound         —— WebAudio 合成音效
3. 工具函数       —— removeAt(交换删除) / POOL(对象池) / segPointDist2(切割判定)
4. TYPES         —— 水果属性表
5. spawnFruit    —— 抛物线发射
6. blade / testCut —— 刀锋轨迹与 AABB 粗筛 + 精确判定
7. slice / boom  —— 切开、粒子、计分
8. update / draw —— 主循环与渲染
9. HUD / 状态机
```

## 🔒 隐私与安全

- **零网络请求**：不含 `fetch` / `XMLHttpRequest` / `WebSocket`，不加载任何外部字体、图片、脚本
- **零密钥**：源码中不含 API Key、Token、密码、私钥、数据库连接串
- **本地存储仅两项**，均为非敏感的游戏数据，可随时清除：
  - `mjk_best` —— 历史最高分
  - `mjk_config` —— 4 个开关的布尔值
- 不采集、不上传任何个人信息；无第三方统计与 Cookie
